# 3D assets (this project)

You are working in kilo-3d-kit. Quality comes from the kit, not from browsing the internet.

- Read `catalog/index.json` before downloading anything.
- Kenney GLBs are static props. KayKit characters are already rigged. Play their clips.
- Do not pull 3dassets.dev, Sketchfab lottery, or AI catalogues.
- If a prop is missing, prefer another Kenney kit over generating a mesh.
- After adding files, run `npm run index` and `npm run inspect`.
