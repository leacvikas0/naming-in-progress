# Workspace planning artifacts

This folder holds the visual studies, scene references, and production plans created for this game. Keep these files inside this repository and committed to Git, rather than in the PC's system temporary folder.

Retain these artifacts until the associated plan has been executed **and the user explicitly approves their deletion**. Completing implementation alone does not authorize cleanup. Do not automatically expire or remove this folder.

Deployment caches, local environment files, and dependencies are excluded from Git.
