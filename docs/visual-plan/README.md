# Haru-machi visual planning draft

Open `index.html` locally. This self-contained folder uses relative assets and no runtime, external fonts, network calls, account, or build step. It can later be hosted as a static directory after approval. Nothing has been deployed.

The page is a review artifact, not approved gameplay behavior. Checkboxes are deliberately temporary and do not approve implementation or save data. Two image-generated UI directions from the parent thread are included for discussion.

## UI concept provenance

`assets/ui-ornate-concept.png` and `assets/ui-quiet-heal-concept.png` were generated by the built-in imagegen tool in the parent thread. Condensed prompt direction: historical arena/tablet screenshot as reference; plum, ivory and gold botanical HUD; one ornate combat direction and one restrained simple-heal direction. The images alter the scene and characters and contain placeholder health numbers inconsistent with actual game stats. They are concepts, not implementation evidence or approved UI. Original generated files were preserved.

## Validation

Local HTML link/asset and anchor checks pass. Mobile viewport, stacked layouts, horizontal chapter navigation, tap-sized controls and a reduced-motion rule are present. Browser rendering and device interaction were not tested; no server was started. Large existing PNGs are retained unmodified, so image optimization remains a packaging task before phone hosting.
